# RPG-game-2d-android
RPG Real time 2d for Android or PC 

в игре будет зонирование / область которую будет видеть игрок.  типо сетки 

на дальность видимости клеток будет влиять стата зрения 

тоесть полу прозрачная сетка которая идёт поверх текстуры карты 

+ персонаж смотрит на 3 клетки вперед и может бить только в том направлении 

разные типы мечей бюьт по разным областям. например клинок меч на клетку в перёд 

клеймор на 3 клетки по бокам которую видит персонаж тоесть левую среднюю правую 

шпага компье 2/3 в перёд без боковых + диагонали 2/3 в перёд 

игрок может бить только в ту сторону в которую смотрит

у персонажа 2 зависимости 

1 - круглая область видимости после которой все серое 
2- областная видимость клеток после которой клеток не видно
